# assets/img/

This folder contains image assets for the UI. Do NOT commit large images encoded as Base64. Instead add optimized images (WEBP/AVIF/JP2) to these filenames:

- hero-lux.jpg            <-- hero background (1920x1080 or responsive variants)
- service-polish.jpg      <-- polish card image
- service-ppf.jpg         <-- ppf card image
- service-ceramic.jpg     <-- ceramic card image

You can replace these with your own high-quality images. Leave this README as guidance.
